# Media Widgets

Media Widgets 是为 [Class Widgets 2](https://github.com/RinLit-233-shiroko/Class-Widgets-2) 设计的插件，用于以小组件形式在屏幕上显示当前播放的媒体信息，并附带一个独立的逐字歌词小组件。
**安装此插件后，你必须以管理员身份运行 Class Widgets 才能使得 Class Widgets 正常启动且插件可以正常使用。**

## 平台支持

| 平台 | 数据源 | 说明 |
| --- | --- | --- |
| Windows | SMTC（系统媒体传输控制） | 系统原生支持，多数播放器（网易云音乐、Spotify 等）都能读取 |
| Linux | MPRIS（通过 D-Bus） | 需要桌面环境提供 D-Bus 会话总线，并播放来自支持 MPRIS 的播放器（Spotify、Rhythmbox、VLC 等）的歌曲；切换播放器时插件会自动跟随正在播放的那个 |

同一安装包同时兼容两个平台，插件启动时按系统自动选择数据源。歌词组件与媒体组件在两个平台行为一致。

## 功能

- 媒体小组件：显示当前歌曲标题、歌手、专辑封面与播放进度
- 专辑主色渐变背景：从封面提取两个主色渲染半透明渐变，进度以遮罩横向填充；两种小组件可分别开关并调节渐变浓度
- 播放源图标角标：设置中开启后，媒体组件的专辑封面右下角会叠加显示正在播放的应用图标（Windows 从 SMTC 的 AUMID 解析注册表 / 打包清单 / 进程内嵌图标，Linux 取 MPRIS 的 DesktopEntry 主题图标）
- 歌词小组件：独立的逐字歌词组件，不依赖也不改动「动态通知」
  - **多歌词源**：QQ音乐（QRC 逐字）、酷狗音乐（KRC 逐字）、网易云音乐（LRC 行级），可在设置中选择，或用「自动」按 QQ → 酷狗 → 网易的顺序取第一个匹配
  - **卡拉OK 逐字动画**：逐字歌词按词内时间戳线性填充高亮；长音（>1s）附加 AMLL 风格持续辉光；行级歌词整行高亮，绝不套用逐字效果
  - **日语歌词振假名**：日语歌词的汉字上方以小字显示平假名注音（标准 ruby），与主字同色并跟随卡拉OK 填充进度；注音随 QQ音乐（QRC）的 `[kana:]` 数据自动获取，其余歌词源无此数据时自动不显示，可在设置中整体关闭
  - **换行与换歌动画**：换行时逐词错峰从下方大幅滑入（起步放大 1.32 倍并带过冲回弹），整行配合一次轻微呼吸缩放，另有一条高光从左到右扫过；换歌时整块内容向右抖出、新歌从左侧大幅滑入再回弹归位。幅度可按需在设置中整体关闭，回落为轻量淡入
  - **间奏显示**：相邻两句之间存在 ≥4 秒的长空档（含开头前奏）时，正文换成三个同步呼吸的圆点，间奏结束后无缝切回下一句；间奏末尾提前 250ms 预显示下一句，收尾不回落上一句，也不会出现布局跳动
  - **无歌词自动隐藏**：匹配失败、纯音乐/无实质歌词、或全部候选分数不足时不再从组件列表里移除组件——组件定义、顺序、布局位置与配置全部保留，只做宽度归零 + 淡出；搜索中保持显示以避免闪烁，有效歌词到来后自动淡入恢复
  - **副行显示**：可选择「有翻译显示翻译、没有则显示下一句」「有翻译显示翻译、没有则隐藏」「只显示下一句」或「不显示」
  - 前奏期间显示第一行暗色预览，唱到后自然开始填充
  - 布局语言与媒体小组件一致：副标题显示歌名，正文为当前行（Title 标尺，逐字卡拉OK扫描）+ 副行（译文 / 下一句预览，超宽自动跑马灯），背景为封面双主色渐变，不显示封面图与进度元素
  - 歌词按（歌名、歌手、时长、来源）磁盘缓存，重复播放同一首歌不再请求网络

## 插件设置页

插件自带的同名「Media Widgets」设置页会出现在 CW2 设置 → 插件里，包含：

- **正在播放**：实时展示当前媒体封面、标题、艺人与播放进度（数据与桌面上的媒体小组件同源），卡片右上角同步显示正在播放的应用名称与图标
- **小组件自定义**：用横向页签分别配置媒体组件与歌词组件
  - 媒体组件：播放源图标、渐变背景与浓度、背景播放进度与时间数字，以及副行显示歌手名或进度数字
  - 歌词组件：渐变背景与浓度、歌词源、副行内容策略、振假名与炫酷动画开关，以及原文 / 译文 / 罗马音 / 日语四张标准的字体设置卡（每张卡各自带标题、说明与「字体 + 字重」选择器，可分别设为跟随全局字体；日语字体只作用于含假名的歌词行与假名注音）

设置改动即时生效并持久化到本地配置。

## 本地化

插件界面跟随 CW2 的语言设置（设置 → 通用 → 语言），提供简体中文（源语言）、繁體中文、日本語、English 四种目录，其余语言回落英文；运行中切换语言即时生效。
